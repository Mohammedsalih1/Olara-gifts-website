# Olara Gifts

A bilingual English/Arabic gift storefront built with React, JSX, Vite, and Tailwind CSS.

## Run locally

1. Install Node.js 20.19 or newer (or 22.12 or newer).
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev` and open the local address shown in the terminal.

Use `npm run build` to create a production build in `dist/`.

## Included

- React source in `src/` (JavaScript and JSX; no TSX)
- The Olara Gifts logo, reference design, cropped product imagery, and payment marks in `public/assets/`
- Responsive Arabic/English storefront and WhatsApp order handoff

The brand's Facebook and Instagram profile URLs can be updated in `src/App.jsx` if the official account links differ.
